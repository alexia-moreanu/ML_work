# ML_work

My work for **CS156: Finding Patterns in Data with Machine Learning** (Minerva University).

## First Pipeline: Can my Apple Watch tell me when to slow down?

[`pipeline1/`](pipeline1/) is a personal machine learning pipeline that turns Apple Watch data and a labelled calendar into a morning readiness score, a read on when my body was under load that movement can't explain, and a plan for the weekend.

- **Write-up and results:** [`pipeline1/notebooks/first_pipeline.ipynb`](pipeline1/notebooks/first_pipeline.ipynb)
- **Use it with your own watch data:** [`pipeline1/README.md`](pipeline1/README.md)

My own health data stays on my laptop and is not in this repository. The `pipeline1/demo_data/` folder is synthetic, so anyone can try the code without a watch.
